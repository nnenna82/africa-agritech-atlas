# Prototype (reference only)

- `atlas-prototype.html` is the page code of the live Cowork prototype. It reads its data from Cowork (`window.claude`), so **it will not run on its own** if you double-click it. Use it to see exactly how a feature was done, for example "look at how `vRegion` builds the region page".
- `crop-journeys.html` is the Crop Journeys page. It runs on its own: open it in a browser.

Live links (signed in to Claude):
