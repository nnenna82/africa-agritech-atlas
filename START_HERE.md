# Start here

This folder is everything Claude Code needs to build the real Africa AgriTech Atlas. You don't need to read it all: Claude Code will.

## What's inside (in plain words)
- **CLAUDE.md** – the instructions Claude Code reads first every session: what we're building, the rules, and a progress checklist.
- **docs/** – the detailed plan: what each page does, the phases, how data is organized, colors and fonts, how scores work, and what testers asked for.
- **prompts/** – messages to copy and paste into Claude Code, phase by phase.
- **data/** – all the Atlas content (countries, people, gaps, news…) ready to load.
- **supabase/** – the database setup.
- **prototype/** and **screenshots/** – what we built in Cowork, as a reference.

## Phase 0 in 6 steps (about 1–2 hours)
1. **Make three free accounts:** GitHub (github.com), Vercel (vercel.com, sign up with GitHub) and Supabase (supabase.com, sign up with GitHub).
2. **Install Claude Code** using the course instructions, and make sure Node.js is installed (nodejs.org, the LTS version).
3. **Unzip this package** and rename the folder to `africa-agritech-atlas`. Put it somewhere easy, like Documents.
4. **Open a terminal in that folder** and type `claude` to start Claude Code.
5. **Paste the prompts** from `prompts/phase-0-setup.md`, one at a time. Check each result before moving on.
6. **Done when** "Hello, Atlas" opens at your own Vercel web address on your phone.

## Three habits
- One feature per message. Check it yourself before the next.
- When something works, say "commit and push."
- Never paste passwords or keys into the chat. Claude Code will tell you where to put them.

Stuck? Paste the exact error into Claude Code and ask "what does this mean in plain words, and what should I do?"
