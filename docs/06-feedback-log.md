# Feedback log

What testers said and what changed in the prototype. Build the "changed to" version.

## Round 1
| Feedback | Changed to |
| --- | --- |
| "Solid numbers are harder to justify" | Five color groups instead of scores; real indicator values shown underneath |
| Wanted to go region first, then country | Home → Africa → region → country, with breadcrumbs |
| Wanted a home page with a clickable map of Africa | New Home page: clickable map + five region cards |
| "Interested in" barely changed anything | Interest panel on Home: plain explanation of that part of the chain, top gaps, who is working on it, map colored by where gaps are documented |
| Country list in the bar was too long | Region dropdown first; Country stays locked until a region is picked |
| Map stretched when a region was picked | Home map no longer zooms (other regions fade); region pages keep the map's proportions |
| Want chat and downloadable learning material | Planned for Phase 5 |

## Round 2
| Feedback | Changed to |
| --- | --- |
| Crop Journeys hard to find | Gold menu button next to Home, a band of four crop cards at the top of Home, crop cards on country pages |
| Want daily African agriculture news | News page (newest first, "why it matters", source link) and the latest three stories on Home |
| Didn't understand the "Add entry" tab | Renamed "Suggest an addition or correction", moved out of the menu to a box at the end of each page, with the three-step explanation; moved to Phase 3 |

## Known issues in the prototype (do not copy)
- On phones, the menu squeezes beside the title. Build a proper menu button that opens the menu on small screens.
- Screenshots show a square-tile map because the screenshot tool could not load the map library. The real site must draw actual country shapes.
